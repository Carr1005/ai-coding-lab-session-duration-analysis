How time is calculated

For each learner, we add up all the time they spent on a lesson across every visit. Each visit's duration = time until they navigated away.

  • Average: add every learner's total time together, divide by the number of learners.
  • P25 / Median / P75 / P90: sort all learners by total time spent, pick the value at that position.
  • Unique users: count each learner once, regardless of how many times they visited.
